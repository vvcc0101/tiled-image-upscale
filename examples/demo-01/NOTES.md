# 案例 01：插画 8× 分块放大

由维护者本人使用本技能生成并授权公开的案例。图片为维护者自有素材，按本仓库 [MIT 许可](../../LICENSE) 一并提供，仅作为效果展示，不构成对其他作品、商标或肖像的授权。

## 参数

| 项 | 值 |
|---|---|
| 模型 | `gpt-image-2.6-sunburst` |
| 生成分辨率设置 | 4K |
| 放大倍率 | 8×（宽、高各 8 倍） |
| 原图尺寸 | 768 × 1024 |
| 输出尺寸 | 6144 × 8192（约 5033 万像素） |
| 处理方式 | 重叠分块生成 + 融合拼接 |

> 参数依据生成时截图记录；图片实际尺寸已核实。**未核实各块的真实返回尺寸**，因此不宣称输出全部为原生生成细节。

## 文件

| 文件 | 说明 |
|---|---|
| `original-768x1024.png` | 原图（768 × 1024，带透明通道） |
| `upscaled-8x-6144x8192.jpg` | 8× 输出（6144 × 8192，16.6 MB） |
| `comparison-01.png` | 前后对比图（1414 × 881，缩放显示） |
| `comparison-02.png` | 另一处局部对比（1489 × 859，缩放显示） |

## 关于"4K 与 8×"

- **4K** 是生成时的**单块分辨率设置**，不是最终成品尺寸。
- **8×** 指宽、高各放大 8 倍，总像素为原图的 **64 倍**。
- **请求 2048 不等于返回 2048，输出 4 倍像素也不等于获得原生 4 倍生成细节。**

## 自检建议

对比时请查看**原尺寸局部**，重点检查：

- 线条是否在原位置、有无双线或断裂
- 文字/符号是否被模型改写（本案例不保证文字准确）
- 接缝处纹理与颜色过渡
- 大面积平涂区域是否出现噪点或渐变带

合成图仅作示例，不代表普遍性能基准，也不用于 PSNR/SSIM 之类的高分辨率真值证明。
